# Mukul Focus Board

A small static web app for planning the day, tracking tasks, keeping quick notes, and running a 25-minute focus timer.

## Files

- `index.html` - app structure
- `styles.css` - responsive styling
- `app.js` - tasks, notes, timer, and local browser storage
- `vercel.json` - Vercel routing settings

The app runs as a static site and does not need a build step.
